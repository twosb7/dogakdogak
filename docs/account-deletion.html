도각도각 키보드 - 계정 및 데이터 삭제

앱 내에서 계정 삭제하기

도각도각 키보드 앱에서 직접 계정을 삭제할 수 있습니다.

  1. 도각도각 키보드 앱을 엽니다.
  2. 설정 탭으로 이동합니다.
  3. 로그인 카드에서 "계정 삭제"를 탭합니다.
  4. 확인 다이얼로그에서 "삭제"를 탭합니다.

삭제되는 데이터

계정 삭제 시 다음 데이터가 모두 영구적으로 삭제됩니다:

  • 이메일 주소
  • 닉네임
  • 프로필 사진 정보
  • 타이핑 통계 및 랭킹 데이터
  • 계정 인증 정보
주의: 계정 삭제는 되돌릴 수 없습니다. 삭제 후 동일한 소셜 계정으로 다시 로그인하면 새로운 계정이 생성됩니다.
