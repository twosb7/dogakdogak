# Google Play Data Safety 작성 기준

Play Console > 앱 콘텐츠 > 데이터 안전 섹션은 아래 실제 앱 동작과 맞춰서 입력한다.

## 1. 기본 질문

| 질문 | 답변 |
|------|------|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **예** |
| 전송 중 데이터가 암호화되나요? | **예** |
| 사용자가 삭제를 요청할 수 있나요? | **예** |

삭제 요청 경로:
- 앱 내 설정 > 계정 삭제
- 외부 URL: `https://twosb7.github.io/dogakdogak/delete-account.html`

## 2. 수집/전송하는 데이터

### 개인정보

| 데이터 유형 | 수집 여부 | 공유 여부 | 목적 | 선택/필수 |
|------------|----------|----------|------|----------|
| 이메일 주소 | 수집 | 공유 안 함 | 계정 관리 | 선택 |
| 사용자 이름 / 닉네임 | 수집 | 공유 안 함 | 앱 기능(랭킹/프로필) | 선택 |
| 프로필 사진 | 수집 | 공유 안 함 | 앱 기능(랭킹/프로필) | 선택 |

### 앱 활동

| 데이터 유형 | 수집 여부 | 공유 여부 | 목적 | 선택/필수 |
|------------|----------|----------|------|----------|
| 앱 내 상호작용 (총 점수/총 터치 수) | 수집 | 공유 안 함 | 앱 기능(전체 랭킹) | 선택 |
| 앱 내 상호작용 (지원 앱별 타이핑/터치 집계) | 수집 | 공유 안 함 | 앱 기능(앱별 랭킹) | 선택 |
| 구매 내역 | 수집 | 공유 안 함 | 앱 기능(구매 복원/검증) | 필수 |

주의:
- 앱별 집계는 로그인 전/설정 화면에서 동의한 경우에만 서버로 전송한다.
- 입력 텍스트 내용은 포함되지 않는다.
- 앱 제안용으로 설치된 앱 이름을 읽거나 전송하지 않는다.

## 3. 수집하지 않는 항목

아래는 Play Data Safety에서 **수집 안 함** 또는 해당 없음으로 정리한다.

- 텍스트 입력 내용 / 메시지 내용
- 설치된 앱 이름
- 정확한 위치 / 대략적 위치
- 연락처 데이터의 서버 전송
- 마이크 원본 오디오의 서버 전송
- 광고 ID / IMEI 등 기기 식별자
- 사진 / 동영상 / 파일
- 건강 / 금융 / 캘린더 데이터

## 4. 권한 관련 설명

- `READ_CONTACTS`
  - 연락처 기반 추천 기능을 사용자가 켜고 앱 내 안내를 확인한 경우 기기 내에서만 사용
  - 도각도각 서버로 업로드하지 않음
- `RECORD_AUDIO`
  - 음성 입력 기능 사용 시에만 필요
  - 권한 요청 전 앱 내 안내 화면을 먼저 표시
  - 도각도각 서버로 업로드하지 않음
- `SYSTEM_ALERT_WINDOW`
  - 콤보 오버레이 기능용

## 5. 리뷰 전에 다시 확인할 것

- 온보딩/설정 화면의 동의 문구가 Data Safety 설명과 일치하는지
- 개인정보처리방침 URL이 최신인지
- 외부 삭제 URL이 열리는지
- "키 입력 내용은 수집하지 않음" 문구가 스토어 설명과 처리방침 모두에 들어가 있는지
