# Google Play Data Safety 양식 작성 가이드

Play Console > 앱 콘텐츠 > 데이터 안전 섹션에서 아래 내용을 입력합니다.

## 1. 데이터 수집 및 공유 개요

| 질문 | 답변 |
|------|------|
| 앱에서 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 수집된 모든 사용자 데이터가 전송 중에 암호화되나요? | **예** (HTTPS/TLS) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예** (앱 내 계정 삭제) |

## 2. 수집하는 데이터 유형

### 개인정보
| 데이터 유형 | 수집 여부 | 공유 여부 | 용도 | 선택/필수 |
|------------|----------|----------|------|----------|
| 이메일 주소 | **수집** | 공유 안함 | 계정 관리 | **선택** (게스트 가능) |
| 이름/닉네임 | **수집** | 공유 안함 | 앱 기능 (랭킹 표시) | **선택** |
| 프로필 사진 | **수집** | 공유 안함 | 앱 기능 (랭킹 표시) | **선택** |

### 앱 활동
| 데이터 유형 | 수집 여부 | 공유 여부 | 용도 | 선택/필수 |
|------------|----------|----------|------|----------|
| 앱 내 상호작용 (타이핑 통계) | **수집** | 공유 안함 | 앱 기능 (랭킹) | **필수** |
| 구매 내역 | **수집** | 공유 안함 | 앱 기능 | **필수** |

### 수집하지 않는 항목 (모두 "수집 안함" 선택)
- 위치 (대략적/정확한)
- 전화번호
- 주소
- 금융 정보 (결제 정보는 Google Play가 처리)
- 건강 정보
- 메시지
- 사진/동영상
- 오디오
- 파일
- 캘린더
- 연락처
- 기기 ID
- **텍스트 입력/키 입력 데이터 — 절대 수집하지 않음**

## 3. 데이터 처리 목적

각 수집 항목에 대해 아래 목적을 선택:
- **계정 관리** → 이메일, 닉네임
- **앱 기능** → 타이핑 통계, 프로필 사진, 닉네임
- **분석** → 선택 안 함 (수집하지 않음)
- **광고** → 선택 안 함 (광고 없음)
- **사기 방지/보안** → 선택 안 함

## 4. 키보드 앱 관련 추가 안내

Google Play는 키보드 앱에 대해 **특별히 주의깊게 심사**합니다.

Data Safety 섹션의 "Preview" 화면에서 다음을 반드시 확인:
- "이 앱은 키 입력 데이터를 수집하지 않습니다"가 명확히 표시되는지
- "데이터가 제3자와 공유되지 않습니다"가 표시되는지

## 5. 개인정보 처리방침 URL

Play Console > 스토어 등록정보 > 개인정보 처리방침 URL에 입력:
- GitHub Pages 등으로 호스팅: `https://[username].github.io/dogakdogak/privacy-policy.html`
- 또는 Supabase Storage에 업로드하여 공개 URL 사용
