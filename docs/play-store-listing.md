# Google Play Store 등록 정보 가이드

| 항목 | 내용 |
|------|------|
| 앱 이름 | 도각도각 - ASMR 타건음 키보드 |
| 앱 이름 (영문) | Dogakdogak - ASMR Typing Sound Keyboard |
| 패키지명 | com.dogakdogak.keyboard |
| 카테고리 | 도구 > 키보드 |
| 콘텐츠 등급 | 전체 이용가 |

## 짧은 설명

```
ASMR 타건음, 콤보 오버레이, 글로벌 랭킹을 담은 감성 키보드
```

## 자세한 설명에 반드시 들어갈 내용

- 입력한 텍스트 내용은 수집하거나 서버로 전송하지 않음
- 로그인 후 전체 랭킹용 점수/터치 수를 동기화함
- 앱별 랭킹은 별도 동의 후에만 지원 앱별 집계가 동기화됨
- 설치된 앱 이름을 추천용으로 읽거나 업로드하지 않음
- 닉네임/아바타는 선택 사항
- 음성 입력은 별도 안내 후 마이크 권한 사용, 연락처 추천은 별도 안내 후 연락처 권한 사용
- 계정 삭제는 앱 내 설정과 외부 삭제 URL 둘 다 제공

## 권한 설명 메모

### SYSTEM_ALERT_WINDOW
```
도각도각 키보드의 콤보 오버레이를 표시하기 위해 사용됩니다.
사용자가 기능을 켠 경우에만 화면 위에 콤보 카운터와 이펙트를 보여줍니다.
```

### 민감 데이터 관련 안내
```
이 앱은 입력한 텍스트 내용을 수집하지 않습니다.
랭킹 기능 사용 시 총 점수/터치 수만 동기화하며,
앱별 랭킹은 사용자가 별도 동의한 경우에만 지원 앱별 집계가 동기화됩니다.
설치된 앱 이름을 추천용으로 읽지 않으며, 연락처와 마이크는 사용자가 기능을 켠 뒤 별도 안내를 확인한 경우에만 사용됩니다.
```
