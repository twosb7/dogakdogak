## 자세한 설명 (4000자 이내)

```
도각도각은 타이핑의 즐거움을 되찾아주는 ASMR 키보드입니다.

[타건음]
14가지 기계식 스위치 사운드를 실제 키보드처럼 들을 수 있습니다.
- 적축, 청축, 갈축, 흑축, 은축
- 조약돌 시리즈 (11종)
각 스위치마다 여러 샘플이 랜덤 재생되어 실제 타건감을 느낄 수 있습니다.

[콤보 이펙트]
빠르게 타이핑하면 콤보가 쌓이고, 플로팅 오버레이에 실시간으로 표시됩니다.
프리미엄 콤보 이펙트를 구매하면 파티클 불꽃놀이와 진동 이펙트를 경험할 수 있습니다.

[랭킹]
타이핑 점수를 다른 사용자와 비교하고, 일간/주간/월간 랭킹에 도전하세요.

[커스터마이징]
- 오버레이 크기, 위치, 색상 조절
- 터치 활성화/비활성화
- 오버레이 표시 ON/OFF

[키보드 기능]
HeliBoard 오픈소스 키보드 기반으로 한국어, 영어 입력을 지원합니다.
- 자동 완성 및 단어 추천
- 클립보드 히스토리
- 이모지 팔레트
- 한 손 모드

개인정보 보호: 입력한 텍스트는 수집하거나 서버로 전송하지 않습니다.
```

## 스크린샷 가이드

Play Store에 최소 2장, 권장 4-8장 스크린샷 필요:

1. **메인 키보드 화면** — 타건음 재생 중 키보드 모습
2. **스위치 선택 화면** — 14가지 스위치 타입 목록
3. **콤보 오버레이** — 높은 콤보에서 이펙트 표시
4. **랭킹 화면** — 사용자 랭킹 표시
5. **이펙트 설정** — 오버레이 커스터마이징
6. **프리미엄 이펙트 미리보기** — 바텀시트 체험 화면
