Dogakdogak Keyboard Privacy Policy

Effective Date: February 18, 2026 | Last Updated: February 18, 2026

1. Overview

"Dogakdogak Keyboard" ("the App") is an Android keyboard application that provides ASMR typing sounds. This Privacy Policy explains what information the App collects, how it is used, and how it is protected.

2. Information We Collect

2-1. Keystroke Data

The App does NOT collect, store, or transmit any text content that users type (characters, words, sentences, or passwords).

The keyboard processes key events temporarily for input handling, but this data is used only on the device and is never transmitted to any server.

2-3. Information We Do NOT Collect

  • Text content typed by the user (characters, words, sentences, passwords)
  • Location data
  • Contacts, call logs
  • Device identifiers (IMEI, advertising ID)
  • Usage information from other apps

3. How We Use Information

  • Account management: User identification via social login (Google, Kakao)
  • Ranking service: Displaying leaderboards based on typing statistics
  • Purchase management: Verifying in-app purchase status (premium sounds, effects)
  • Service improvement: App stability and quality (anonymous crash logs)

4. App Permissions

4-1. Display Over Other Apps (SYSTEM_ALERT_WINDOW)

This permission is used for the combo overlay feature. It displays a real-time combo counter and effect animation above the keyboard while typing. Users can freely enable or disable this feature in the app settings.

4-2. Internet (INTERNET)

Used for social login, ranking data synchronization, and in-app purchase processing.

5. Information Sharing

The App does not sell or share user personal information with third parties for advertising purposes.

We share minimal necessary information with the following service providers:

  • Supabase: Authentication and data storage (email, nickname, typing statistics)
  • Google Play: In-app purchase processing
  • Google Sign-In / Kakao: Social login authentication

6. Data Security

  • All server communications are encrypted via HTTPS/TLS.
  • Authentication tokens are stored in on-device secure storage.
  • Passwords are stored as one-way hashes by Supabase.

7. Children's Privacy

The App does not intentionally collect personal information from children under 13. If we become aware that such information has been collected, we will delete it immediately.

8. User Rights

  • Access: View stored information on the profile screen within the App
  • Correction: Change nickname and profile picture
  • Deletion: Request account deletion in App settings; all personal data will be deleted
  • Contact: Reach out via the contact information below for privacy inquiries

9. Changes to This Policy

If this Privacy Policy is updated, we will notify users through app update notes or in-app announcements.
