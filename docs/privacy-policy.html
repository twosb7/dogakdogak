도각도각 키보드 개인정보 처리방침

시행일: 2026년 2월 18일 | 최종 수정: 2026년 2월 18일

1. 개요

"도각도각 키보드"(이하 "앱")는 ASMR 타건음을 제공하는 안드로이드 키보드 앱입니다. 본 개인정보 처리방침은 앱이 수집하는 정보, 사용 목적, 보호 방법을 설명합니다.

2. 수집하는 개인정보

2-1. 키 입력 데이터

앱은 사용자가 입력하는 텍스트 내용(글자, 단어, 문장)을 수집하거나 저장하거나 전송하지 않습니다.

키보드는 입력 처리를 위해 일시적으로 키 이벤트를 처리하지만, 이 데이터는 기기 내에서만 사용되며 어떤 서버로도 전송되지 않습니다.

2-2. 수집하는 정보

2-3. 수집하지 않는 정보

  • 입력한 텍스트 내용 (글자, 단어, 문장, 비밀번호 등)
  • 위치 정보
  • 연락처, 통화 기록
  • 기기 고유 식별자 (IMEI, 광고 ID 등)
  • 다른 앱의 사용 정보

3. 정보의 사용 목적

  • 계정 관리: 소셜 로그인(Google, 카카오)을 통한 사용자 식별
  • 랭킹 서비스: 타이핑 통계 기반 순위 표시
  • 구매 관리: 인앱 구매(프리미엄 사운드, 이펙트) 상태 확인
  • 서비스 개선: 앱 안정성 및 품질 향상 (익명 크래시 로그)

4. 앱 권한 사용 목적

4-1. 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW)

이 권한은 콤보 오버레이 기능에 사용됩니다. 키보드 타이핑 시 실시간 콤보 카운터와 이펙트 애니메이션을 키보드 위에 표시하기 위해 필요합니다. 이 기능은 사용자가 설정에서 자유롭게 켜고 끌 수 있습니다.

4-2. 인터넷 (INTERNET)

소셜 로그인, 랭킹 데이터 동기화, 인앱 구매 처리에 사용됩니다.

5. 정보의 공유 및 제3자 제공

앱은 사용자의 개인정보를 제3자에게 판매하거나 광고 목적으로 공유하지 않습니다.

다음 서비스 제공자와 필요 최소한의 정보를 공유합니다:

  • Supabase: 인증 및 데이터 저장 (이메일, 닉네임, 타이핑 통계)
  • Google Play: 인앱 구매 처리
  • Google Sign-In / Kakao: 소셜 로그인 인증

6. 데이터 보안

  • 모든 서버 통신은 HTTPS/TLS로 암호화됩니다.
  • 인증 토큰은 기기 내 보안 저장소에 저장됩니다.
  • 비밀번호는 Supabase에서 단방향 해시로 저장됩니다.

7. 아동 보호

앱은 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 13세 미만 사용자의 정보가 수집된 것을 인지할 경우, 즉시 해당 정보를 삭제합니다.

8. 사용자 권리

사용자는 다음 권리를 행사할 수 있습니다:

  • 정보 열람: 앱 내 프로필 화면에서 저장된 정보 확인
  • 정보 수정: 닉네임, 프로필 사진 변경
  • 계정 삭제: 앱 내 설정에서 계정 삭제 요청 시 모든 개인정보가 삭제됩니다
  • 문의: 아래 연락처로 개인정보 관련 문의 가능

9. 처리방침 변경

본 처리방침이 변경될 경우, 앱 업데이트 노트 또는 앱 내 공지를 통해 안내합니다.
