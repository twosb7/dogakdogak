도각도각 키보드 개인정보 처리방침

시행일: 2026년 3월 7일 | 최종 수정: 2026년 3월 7일

1. 개요

"도각도각 키보드"(이하 "앱")는 안드로이드 키보드 앱입니다. 본 처리방침은 앱이 어떤 데이터를 기기 내에서 처리하고, 어떤 데이터를 서버로 동기화하며, 사용자가 데이터를 어떻게 삭제할 수 있는지 설명합니다.

중요: 앱은 사용자가 입력하는 텍스트 내용(문장, 단어, 비밀번호, 복사한 내용)을 수집하거나 저장하거나 도각도각 서버로 전송하지 않습니다.

2. 수집 또는 동기화하는 정보

2-1. 계정 및 프로필 정보

2-2. 랭킹 및 통계 정보

항목기본 여부이용 목적보관 기간
총 점수 / 총 터치 수로그인 후 랭킹 참여 중 키보드 사용 시 동기화전체 랭킹 제공계정 삭제 시까지
지원 앱별 타이핑 수 / 터치 수앱 내 동의 후, 키보드 사용 시에만 동기화앱별 랭킹 제공계정 삭제 시까지

앱별 통계는 앱이 지원하는 고정된 앱 목록에서만 사용되며, "어떤 앱에서 몇 번 타이핑/터치했는지"에 대한 집계값만 다룹니다. 입력한 텍스트 내용 자체는 포함되지 않습니다.

3. 서버로 전송하지 않는 정보

  • 사용자가 입력한 텍스트 내용, 비밀번호, 문장, 복사한 내용
  • 정확한 위치 정보
  • 광고 ID, IMEI 등 기기 고유 식별자
  • 동의하지 않은 앱별 사용 통계
  • 설치된 앱 이름을 추천용으로 수집하거나 서버로 전송하는 행위
  • 연락처 원본 데이터
  • 마이크 원본 오디오를 도각도각 서버로 업로드하는 행위

4. 권한 및 기기 내 처리

4-1. 마이크 (RECORD_AUDIO)

음성 입력 기능을 사용할 때만 필요하며, 권한 요청 전에 앱 내 안내 화면을 먼저 표시합니다. 음성 데이터는 도각도각 서버로 전송하지 않으며, 사용 중인 음성 입력 서비스 또는 운영체제 정책의 적용을 받을 수 있습니다.

4-2. 연락처 (READ_CONTACTS)

사용자가 연락처 기반 추천 기능을 켜고 앱 내 안내를 확인한 뒤 권한을 허용한 경우에만 기기 내 추천/교정 품질 향상에 사용됩니다. 연락처 데이터는 도각도각 서버로 업로드하지 않습니다.

4-3. 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW)

콤보 오버레이를 키보드 위에 표시하기 위해 사용됩니다. 사용자가 설정에서 켠 경우에만 사용됩니다.

4-4. 인터넷 (INTERNET)

로그인, 랭킹 동기화, 프로필 이미지 업로드, 구매 검증 및 계정 삭제 처리에 사용됩니다.

5. 정보 이용 목적

  • 계정 인증 및 로그인 유지
  • 전체 랭킹 및 앱별 랭킹 제공
  • 프로필 표시
  • 인앱 구매 검증 및 복원
  • 앱 안정성 유지 및 고객 문의 대응

6. 제3자 제공 및 처리 위탁

앱은 개인정보를 광고 판매 목적으로 제3자에게 판매하지 않습니다. 다만 아래 서비스에 필요한 범위의 데이터 처리를 맡깁니다.

  • Supabase: 계정, 프로필, 랭킹 데이터, 계정 삭제 처리
  • Google Play: 인앱 구매 처리 및 검증
  • Google / Kakao: 소셜 로그인 인증

7. 보안

  • 서버 통신은 HTTPS/TLS로 암호화됩니다.
  • 계정 삭제는 서버 측 함수에서 프로필, 랭킹, 앱별 통계, 구매 동기화 기록, 아바타를 함께 제거하도록 처리합니다.
  • 기기 내부 설정과 토큰은 안드로이드 저장소에 보관됩니다.

8. 계정 및 데이터 삭제

사용자는 다음 두 가지 방법으로 계정 및 관련 데이터를 삭제할 수 있습니다.

  • 앱 내: 설정 화면에서 계정 삭제
  • 웹 안내 페이지: https://twosb7.github.io/dogakdogak/delete-account.html

계정 삭제가 완료되면 프로필, 랭킹 점수, 앱별 랭킹 통계, 구매 동기화 기록, 아바타 이미지가 삭제 대상에 포함됩니다.

9. 아동 개인정보

앱은 13세 미만 아동을 대상으로 설계되지 않았으며, 관련 개인정보를 의도적으로 수집하지 않습니다.
