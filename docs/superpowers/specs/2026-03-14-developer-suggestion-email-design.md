# 개발자 건의 메일 Design

## 목표

설정 화면 맨 아래에 `개발자에게 건의하기` 액션을 추가하고, 구글/카카오 로그인 사용자만 앱 내부 입력 폼을 통해 메일 앱으로 건의를 보낼 수 있게 한다.

## 요구사항

- 버튼은 설정 화면 하단 `앱 정보` 카드 안, `GPL-3.0 License` 아래에 둔다.
- 비로그인 사용자는 버튼을 볼 수는 있지만, 누르면 로그인 필요 안내만 보여준다.
- 로그인 사용자는 앱 내부 다이얼로그에서 제목과 내용을 입력한다.
- 작성 UI는 기본 AlertDialog 대신 바텀시트 형태로 제공한다.
- 설정 화면 버튼 아래에 보상 안내 문구를 함께 노출한다.
- 제출 시 메일 앱이 열리고 수신자는 `dogak.sw@gmail.com`으로 고정한다.
- 메일 제목/본문에는 로그인 이메일, 로그인 제공자, 사용자 UID, 앱 버전, 건의 제목/내용을 포함한다.
- 서버 저장, 전송 이력, 자동 보상 지급은 이번 범위에 포함하지 않는다.

## 설계

- `DeveloperSuggestion.kt`에 메일 포맷용 순수 모델과 helper를 둔다.
- `SettingsActivity`는 현재 Supabase 세션에서 이메일/제공자/UID를 읽어 `DogakdogakSettingsScreen`에 전달하고, 제출 시 메일 인텐트를 연다.
- `SettingsScreen`은 하단 버튼, 로그인 필요 다이얼로그, 건의 작성 다이얼로그만 담당한다.
- `SettingsScreen`의 건의 작성 UI는 Toss 스타일의 큰 타이틀, 보조 설명, 부드러운 라운드 입력칸, 하단 CTA가 있는 바텀시트로 구성한다.

## 오류 처리

- 로그인 이메일을 읽지 못하면 작성 다이얼로그 대신 안내 다이얼로그를 띄운다.
- 메일 앱이 없으면 `Toast`로 실패를 안내한다.

## 테스트

- 메일 helper 단위 테스트로 수신자, 제목, 본문 필수 필드를 검증한다.
- `SettingsActivityStabilityTest`로 설정 화면 런치 회귀가 없는지 확인한다.
