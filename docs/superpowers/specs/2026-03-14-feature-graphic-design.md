# Feature Graphic Design Spec

## 목표

안드로이드 마켓 검색 결과에 노출되는 feature graphic을 현재 앱 아이콘과 같은 결로 정리한다. 기존 배너의 과한 3D/광택/AI 느낌을 줄이고, 아이콘의 파스텔 톤과 둥근 손그림 감성을 확장한 브랜딩 카드처럼 보이게 만든다.

## 디자인 방향

- 전체 비율은 Play feature graphic 규격인 `1024x500`
- 배경은 아이콘의 `크림 + 하늘색` 계열을 확장한 부드러운 그라데이션
- 좌측에는 현재 앱 아이콘을 크게 배치
- 우측에는 제품명 `조약돌 소리나는 키보드 어플`
- 보조 포인트로 iOS 감성의 둥근 `ASMR` 필 버튼 추가
- 불필요한 3D 키보드, 손가락, 안드로이드 캐릭터, 과한 반짝이 요소는 제거

## 시각 원칙

- 아이콘과 같은 파스텔 팔레트 사용
- 텍스트는 또렷하되 입체감은 최소화
- 작은 썸네일에서도 읽히는 명도 대비 확보
- 광고 배너보다 앱 브랜드 소개 카드처럼 보이게 구성
