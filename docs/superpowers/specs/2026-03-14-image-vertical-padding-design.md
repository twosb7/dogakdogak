# Image Vertical Padding Design Spec

## 목표

사용자가 제공한 이미지를 비율 왜곡 없이 `9:16` 세로 캔버스에 맞추고, 부족한 영역은 흰색 여백으로 채운 뒤 해상도를 `1080x1920`으로 개선한 PNG를 만든다.

## 디자인 방향

- 결과물은 `1080x1920` `PNG`
- 원본 비율은 유지
- 남는 영역은 순백색으로 채움
- 원본 중앙 구도를 유지
- 업스케일 후 가벼운 샤프닝으로 선명도를 보정

## 구현 방식

- 원본을 `9:16` 캔버스 안에 비율 유지로 리사이즈
- 흰 배경 위 중앙 정렬로 배치
- 최종 해상도를 `1080x1920`으로 저장
