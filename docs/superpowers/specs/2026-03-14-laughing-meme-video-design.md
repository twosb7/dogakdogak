# Laughing Meme Video Design Spec

## 목표

사용자가 제공한 밈 이미지를 세로형 `9:16` 영상으로 재구성하고, 화면에 보이는 모든 요소가 함께 조금씩 떨리는 빠른 루프 애니메이션을 만든다.

## 디자인 방향

- 결과물은 `1080x1920` 무음 `mp4`
- 총 길이는 약 `4초`
- 처음과 끝이 자연스럽게 이어지는 무한 반복형 루프
- 원본 밈의 흰 배경과 손그림 느낌은 유지
- 흔들림은 과장되지 않되 빠르게 체감되는 `중간` 강도

## 구현 방식

- 원본 이미지를 `9:16` 캔버스에 맞게 고해상도로 업스케일
- 업스케일된 전체 이미지를 하나의 레이어처럼 다룬다
- 프레임마다 전체 캔버스에 짧은 주기의 미세 이동과 약한 회전을 적용한다
- 각 프레임은 PIL로 렌더링하고 `ffmpeg`로 `mp4` 인코딩

## 산출물

- 렌더 스크립트: `tools/render_laughing_meme_video.py`
- 최종 영상: `tmp/laughing-meme-loop.mp4`
