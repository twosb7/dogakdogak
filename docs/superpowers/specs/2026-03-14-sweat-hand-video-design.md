# Sweat Hand Video Design Spec

## 목표

`/Users/twosb/Documents/new/image-9x16-upscaled.png`을 기반으로, 땀 3방울은 계속 맺히는 듯 반복되고 손과 마우스 선만 아주 빠르게 흔들리는 무음 세로 영상을 만든다.

## 디자인 방향

- 결과물은 `1080x1920` 무음 `mp4`
- 길이는 약 `4초`
- 무한 반복에 자연스럽게 이어지는 루프
- 사람, 의자, 모니터, 텍스트, 배경은 정지
- 왼쪽의 땀 3방울만 시간차를 두고 생겼다 약해졌다 내려가는 느낌
- 마우스를 쥔 손과 마우스 선은 초고속 미세 흔들림

## 구현 방식

- 원본 전체를 정적 배경으로 사용
- 땀 영역과 손/마우스선 영역을 각각 별도 레이어로 분리
- 배경에서는 해당 영역을 흰색으로 비워 고스트 현상을 없앰
- 땀은 각 방울의 크기, 불투명도, 위치를 주기적으로 변화
- 손/마우스선은 작은 진폭의 빠른 사인파 이동과 약한 회전 적용
- PIL로 프레임을 렌더링하고 `ffmpeg`로 `mp4` 인코딩

## 산출물

- 렌더 스크립트: `tools/render_sweat_hand_video.py`
- 최종 영상: `tmp/sweat-hand-loop.mp4`
